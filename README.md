# WES120V-obligatorisk-oppgave-1

## Hva prosjektet er
Jeg har laget et vite-prosjekt, som handler om å lage en nettside.

## Node.js og pnpm må være installert
Prosjektet skal kjøres, og for at den skal kjøres må jeg ha node.js og pnpm installert på ubuntu i terminal.

## Hvordan avhengighetene installeres med pnpm install
for å kjøre prosjektet må man laste ned avhengighetene som installeres av å taste inn komandoen pnpm install.

## Hvordan utviklingsserveren startes med pnpm dev
For at serveren eller prosjektet skal starte taster jeg kommandoen pnpm dev, for å gå inn på nettsiden i nettleseren.

## Siden åpnes på adressen Vite viser i terminalen
Da serveren starter ved å taste pnpm dev kommandoen, kommer det en link som ser sånn ut http://localhost:5173/, og denne lenken tar meg til nettsiden min på nettleseren, også blir det sånn at jeg kan se hvordan nettsiden min ser ut.
